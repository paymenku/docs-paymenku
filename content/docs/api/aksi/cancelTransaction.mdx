          `422`.

          - Di produksi, pembatalan hanya tersedia untuk sebagian transaksi
          QRIS.
            Kanal lain dibalas `422`.
          - Transaksi sandbox dibatalkan secara lokal tanpa memanggil penyedia.


          Status berubah menjadi `cancelled`. Webhook `payment.status_updated`

          tetap menjadi sumber status resmi.
